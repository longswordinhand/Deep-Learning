# AgriSafe Reliability: Reproducibility Materials

This directory accompanies the manuscript **“Validity-First Field-Label Budgeting for Reliable Plant Disease Recognition under Distribution Shift”** by Yanhui Guo, David Weng, and Na Yang.

The repository materials support the reported experiments on label-efficient field adaptation, acquisition, calibration recovery, and validity-first allocation under agricultural distribution shift.

## Contents

- `configs/`: frozen experiment/protocol configuration files.
- `manifests/`: source/target split and acquisition manifests used by the study.
- `scripts/`: analysis and experiment code.
- `tables/`: source data for the main publication figures/tables.
- `docs/`: research-contract, claim-gate, and validity-audit documentation.

The public image datasets themselves are **not redistributed here**; they should be obtained from their original providers. The manuscript and supplementary information describe the dataset harmonization and evaluation protocol.

## Reproducibility boundary

These files are the public release materials associated with the journal study. Negative findings and blocked analyses are retained in the project audit trail rather than rewritten as positive results. No manuscript DOI is claimed while the article is under submission.
